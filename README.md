# Blinkit Power BI Dashboard

## Project Overview
This project is a Power BI dashboard created to analyze Blinkit sales data.

## Dashboard Highlights
- Sales Analysis
- Profit Analysis
- Product & Category Analysis
- Outlet Analysis
- Customer & Order Insights
- Interactive Filters and Visualizations

## Tools Used
- Power BI
- Power Query
- DAX
- Data Visualization
